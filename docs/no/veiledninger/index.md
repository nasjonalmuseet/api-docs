# Veiledninger

Veiledningene viser hvordan API-et brukes i praksis: når du bør bruke et kall, hvordan
du gjør det steg for steg, hva svaret betyr, og hva som ofte går galt. Den tekniske
referansen står under [Dokumentasjon](../dokumentasjon/index.md).

Alle eksemplene kjøres automatisk mot API-et, så de virker slik de står.

| Veiledning | Hva du lærer |
|---|---|
| [Kom i gang](kom-i-gang.md) | Lage nøkkel, gjøre det første kallet, prøve i nettleseren |
| [Finn verk](finn-verk.md) | Slå opp ett verk, bla i samlingen og søke på ord |
| [Bilder og IIIF](bilder.md) | Hente bilder, utsnitt og IIIF-manifester til bildevisere |
| [Semantisk søk](semantisk-sok.md) | Søke på betydning, filtrere og finne lignende bilder (ext) |
| [Linked Art](linked-art.md) | Hente verk som koblet data (JSON-LD) |
