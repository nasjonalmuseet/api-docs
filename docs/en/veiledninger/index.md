# Tutorials

The tutorials show how the API is used in practice: when to use a request, how to make it
step by step, what the response means, and what often goes wrong. The technical reference
is under [Documentation](../dokumentasjon/index.md).

All the examples are run automatically against the API, so they work as written.

| Tutorial | What you learn |
|---|---|
| [Getting started](kom-i-gang.md) | Create a key, make the first request, try it in the browser |
| [Find works](finn-verk.md) | Look up one work, browse the collection and search for words |
| [Images and IIIF](bilder.md) | Fetch images, crops and IIIF manifests for image viewers |
| [Semantic search](semantisk-sok.md) | Search by meaning, filter and find similar images (ext) |
| [Linked Art](linked-art.md) | Fetch works as linked data (JSON-LD) |
